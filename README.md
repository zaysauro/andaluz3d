# Elevato Andaluz · Tour 3D

Tour 3D interativo do apartamento tipo de 2 dormitórios (34,6 m²) do Elevato Andaluz, reconstruído a partir do book oficial.

Site estático (HTML + Three.js r170, sem build). Para rodar localmente: `python3 -m http.server` e abra `index.html`.

- `plan.json`: geometria vetorizada da planta (escala 190 px = 1 m)
- `app.js`: cena 3D, navegação e hotspots
- `content.js`: abas Planta e Ambientes

Imagens meramente ilustrativas. Mobiliário e decoração não fazem parte do contrato.
